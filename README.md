## About

This is my personal portfolio site — a place to show what I've built and a bit about how I work. It's deployed straight from this repo to GitHub Pages, with GitHub Actions handling the build and deploy on every push.

**Live site:** [aamirdv.github.io/Portfolio](https://aamirdv.github.io/Portfolio/)

<br>

## Features

- Responsive layout — works on mobile, tablet, and desktop
- Project showcase section
- Contact section with direct links (email, socials)
- Fast load time, no unnecessary dependencies
- Auto-deployed on every push via GitHub Actions

## Project structure

```
Portfolio/
├── frontend/              # React + TypeScript source
└── .github/workflows/     # CI/CD — auto-deploys to GitHub Pages
```

<br>

## Running it locally

```bash
git clone https://github.com/aamirdv/Portfolio.git
cd Portfolio/frontend
npm install
npm run dev
```

<br>

## Deployment

Every push to `master` triggers a GitHub Actions workflow that builds the project and publishes it to GitHub Pages automatically — no manual deploy step needed.
